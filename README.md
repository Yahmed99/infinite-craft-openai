# NYC Crafts (Offline Demo)

NYC Crafts is a local-first, NYC-themed crafting game demo.

Combine familiar NYC concepts (boroughs, attractions, landmarks, subway culture, famous places) to discover new nodes.

This version runs fully offline in the browser with local pairings only.

## Run locally

```bash
cd infinite-craft-openai
npm run install:all
npm run dev
```

Open `http://localhost:5173`.
